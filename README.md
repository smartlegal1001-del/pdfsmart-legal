Questo repository contiene il minisito di **PDF Smart**, app per la lettura e la gestione dei documenti PDF.

## Importante: non pubblicare come documenti definitivi

Le pagine `privacy.html` e `termini.html` sono bozze preparatorie. Prima di usarle negli store o in RevenueCat, verificare:

- Dati legali e recapiti eventualmente richiesti per la distribuzione commerciale in Italia e UE.
- Flussi di dati realmente generati da Google AdMob, Google UMP, RevenueCat e dagli altri SDK dell'app.
- Eventuali strumenti di analisi o crash-reporting e tempi di conservazione.
- Modalità effettive di trattamento dei PDF sul dispositivo e consenso pubblicitario.
- Condizioni di acquisto e ripristino del Premium a vita; prezzo definitivo deciso negli store Apple e Google.
- Diritti dei consumatori e informazioni precontrattuali per i contenuti digitali.
- Verifica professionale dei testi legali prima di rimuovere gli avvisi di bozza.

## Pubblicazione GitHub Pages, dopo le verifiche

Impostare `Settings → Pages → Deploy from a branch → main → /(root)`. Verificare i link di `privacy.html` e `termini.html` in navigazione privata. La sola presenza dei file nel repository **non** abilita GitHub Pages.

File: `index.html`, `privacy.html`, `termini.html`, `style.css`, `pdfsmart-icon.svg` e `.nojekyll`.
